## 🔧 技术说明

- **路径**: `/music/`（自动映射到 `public/music/`）
- **音频格式**: MP3
- **索引机制**: 自动扫描 `public/music/` → 生成 `music-manifest.json`
- **加载方式**: 应用启动时通过 `fetch('/music-manifest.json')` 动态加载
- **版本管理**: 基于 manifest `updatedAt` 时间戳自动版本校验
- **播放引擎**: Howler.js + Web Audio API 双引擎

## 🚀 自动发现机制

```mermaid
flowchart LR
    A[public/music/] -->|generate-music-manifest.cjs| B[music-manifest.json]
    B -->|应用初始化| C[audio-engine.ts]
    C -->|动态加载| D[AudioTrack[]]
    D -->|播放| E[Howler.js / Web Audio API]
```

无需手动配置，新增音乐文件到 `public/music/` 对应子目录后，重启 dev server 即自动加载。
